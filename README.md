# Online Grocery Ordering System

A full-stack MERN application that allows users to browse grocery products, add them to cart, and place orders online.

## Features
- User authentication (login/register)
- Product browsing
- Cart management
- Order placement
- Admin dashboard

## Tech Stack
Frontend: React.js  
Backend: Node.js, Express.js  
Database: MongoDB  
Deployment: Vercel + Render
